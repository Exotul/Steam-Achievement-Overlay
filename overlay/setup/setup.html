Willkommen im Trophäenschrank

Ein Handgriff, dann läuft alles von selbst.

Die App liest deine Achievements über Steams offizielle Schnittstelle. Dafür braucht jede Person einen eigenen Schlüssel — er ist kostenlos und in einer Minute geholt.

  2. Dort erscheint ein Feld Domain — irgendein Text reicht, zum Beispiel localhost. Bestätigen.
  3. Den angezeigten Schlüssel markieren und kopieren (32 Zeichen).
  4. Hier unten einfügen.

Der Schlüssel bleibt auf diesem Rechner. Er wird in eine Datei in deinem Benutzerordner geschrieben und ausschließlich an Steam selbst gesendet — dorthin muss er, sonst lässt sich nichts abfragen. Er wird an keinen anderen Server geschickt, nicht zwischengespeichert und nicht ins Protokoll geschrieben.
